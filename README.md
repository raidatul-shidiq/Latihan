# Tugas Rangkuman Pelatihan Git, GitHub, dan Markdown

Repository ini dibuat untuk memenuhi tugas pelatihan mengenai Version Control System (VCS). Di dalam repository ini, terdapat file `latihan.txt` yang berisi rangkuman lengkap dari materi yang telah dipelajari. 

Proses pembuatan file rangkuman di repository ini telah dikerjakan menggunakan minimal 3 tahapan commit sesuai dengan instruksi tugas.

## 📁 Isi Repository
- `latihan.txt` : Berisi teks rangkuman materi pelatihan.
- `README.md` : File yang sedang Anda baca ini, berfungsi sebagai penjelasan repository.

## 📚 Topik Materi yang Dirangkum
Di dalam `latihan.txt`, rangkuman dibagi menjadi tiga bagian utama, yaitu:

1. **Version Control System (VCS) & Git**
   Membahas konsep dasar pelacakan dan pengelolaan file, 3 jenis VCS (Lokal, Terpusat, Terdistribusi), pengenalan Git, serta perintah-perintah dasar Git (seperti `init`, `add`, `commit`, dan konfigurasi).

2. **GitHub & Remote Repository**
   Membahas cara menyimpan salinan pekerjaan secara online menggunakan GitHub, serta daftar perintah untuk mengelola remote repository (seperti `push`, `fetch`, `pull`, `reset`, dan `log`).

3. **Markdown, Branching, dan Merging**
   Membahas sintaks dasar penulisan Markdown untuk dokumentasi programmer, serta perintah-perintah Git untuk percabangan (seperti `branch`, `switch`, `merge`, dan `rebase`).
